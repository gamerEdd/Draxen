# 📁 LOGOS

Coloca tu logo aquí: `logo.png`

El original `logo.png` se usa como referencia de identidad en toda la tienda. La copia pública exacta está en `frontend/public/assets/brand/logo-source.png`, para que el logo cargue sin depender del backend.

El componente compartido es `frontend/src/components/BrandLogo.jsx`. Los usos, el encuadre y las adaptaciones para fondos claros/oscuros se documentan en `docs/brand.md`.

El backend también conserva la ruta `http://localhost:5000/logos/logo.png`.
