# Alien · Rebelde Neón

Referencia del usuario mejorada con image_gen integrado. Se conservaron el gesto, el texto y los colores; se limpiaron los contornos y se reforzaron texturas, sombras y reflejos. PNG transparente: `frontend/public/assets/designs/alien-rebel.png`.

Disponible en Memes y el personalizador para camisetas y buzos de hombre y mujer. Catálogo compartido con el servidor: 51 diseños y 204 combinaciones. Se conserva la imagen original adjunta.

Arranque: `npm run prod`. Producto: `/producto/tee-men-alien-rebel`.
